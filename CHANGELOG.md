# Changelog

## 0.1.0

- Initial release
- `createDragToSwipe`: mouse drag with momentum, CSS scroll-snap aware release, rubber-band overscroll, click suppression
- `observeSnapIndex`, `createPager`, `observeScrollEdges` and snap utilities
- React bindings: `DragToSwipe`, `useDragToSwipe`, `useSnapIndex`, `useScrollEdges`, `usePager`, `useMergedRefs`, `SnapDots`, `SnapFraction`
- Optional `style.css`
